# Online Student Application Form

A responsive web-based student admission application developed using HTML5, CSS3, and JavaScript.

The application allows prospective students to apply online by submitting personal information, academic qualifications, programme choices, and supporting details through an intuitive and user-friendly interface.

---

# About

The Online Student Application Form was developed as a front-end web development project focusing on digital admission systems, form validation, responsive web design, and modern user interface principles.

The project simulates an online admission platform commonly used by:

- Universities
- Colleges
- Private Institutions
- Training Academies
- Technical Schools
